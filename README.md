# Procedural Styles

Gere sons MIDI de forma procedural de diversos estilos!

> Repositório: Procedural_Styles
> Descrição: Gere sons MID de forma procedural de diversos estilos !!!

---

## Sobre

Este projeto foca na geração procedural de música/MIDI com diferentes estilos. Ele está escrito principalmente em JavaScript, com partes em HTML e CSS para a interface.

Linguagens principais (aprox.):
- JavaScript
- CSS
- HTML

---

## Funcionalidades

- Geração procedural de padrões musicais.
- Exportação/baixar em formato MIDI (dependendo da implementação do projeto).
- Interface web simples para configurar parâmetros (tempo, instrumento, estilo, duração).

> Observação: ajuste as seções abaixo conforme a forma exata como o projeto roda (por exemplo: abrir `index.html`, rodar `npm start`, ou usar um script CLI). Se quiser, eu posso atualizar o README com instruções precisas se você me disser como executar o projeto localmente.

## Como executar (exemplos comuns)

Escolha a opção que corresponde ao seu projeto:

Opção A — Projetos estáticos (HTML/CSS/JS):
1. Abra `index.html` no navegador.

Opção B — Servidor estático via npm (recomendado para evitar restrições do navegador):
1. Instale um servidor estático (ex.: `npm install -g http-server`) ou use `npx http-server`.
2. Na raiz do projeto rode `npx http-server`.
3. Abra `http://localhost:8080` (porta pode variar).

Opção C — Projeto Node com scripts npm:
1. Instale dependências: `npm install`.
2. Rode: `npm start` ou `npm run dev` (substitua pelo script correto se existir).

## Uso

- Abra a interface (ou execute o script) e selecione o estilo desejado.
- Ajuste parâmetros como tempo (BPM), instrumentos, complexidade e duração.
- Clique em "Gerar" e, se disponível, faça o download do arquivo `.mid` gerado.
